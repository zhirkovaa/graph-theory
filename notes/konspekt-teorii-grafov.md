## 1. Основные понятия

*Читать: [Б] гл. 1; [У] §§1–4; [Г] гл. 2.1–2.8.*

**Граф** `G = (V, E)` — множество **вершин** `V` и множество **рёбер** `E`, где каждое ребро соединяет пару вершин. Разновидности:

- **Простой граф** — без петель и кратных рёбер (ребро = неупорядоченная пара различных вершин).
- **Мультиграф** — допускаются кратные рёбра; **псевдограф** — ещё и петли.
- **Ориентированный граф (орграф)** — рёбра (дуги) упорядочены: `(u, v) ≠ (v, u)`.
- **Взвешенный граф** — рёбрам приписаны числа (веса, длины, стоимости).

**Смежность и инцидентность.** Две вершины *смежны*, если соединены ребром; ребро *инцидентно* своим концам. **Степень** `deg(v)` — число рёбер, инцидентных вершине (петля считается дважды). В орграфе различают полустепень исхода `d⁺(v)` и захода `d⁻(v)`.

**Лемма о рукопожатиях** (первая теорема теории графов, Эйлер):

> Σ deg(v) = 2|E| — сумма степеней всех вершин равна удвоенному числу рёбер.

Следствие: **число вершин нечётной степени всегда чётно**.

**Важные семейства графов:**

- `K_n` — полный граф (все пары вершин смежны), `|E| = n(n−1)/2`;
- `O_n` (пустой граф) — рёбер нет;
- `C_n` — цикл, `P_n` — простая цепь (путь);
- `K_{m,n}` — полный двудольный граф; **двудольный граф** — вершины делятся на две доли, все рёбра идут между долями. *Критерий: граф двудолен ⇔ в нём нет циклов нечётной длины.*
- **Регулярный граф** — все степени равны `r` (куб `Q_n`, граф Петерсена — классические примеры);
- **Граф Кнезера** `K(n, k)` — вершины — k-подмножества, рёбра — непересекающиеся пары ([Г] §2.6.3).

**Изоморфизм.** Графы изоморфны, если существует биекция вершин, сохраняющая смежность. Инварианты (необходимые условия): число вершин и рёбер, набор степеней, число компонент, длины циклов. Совпадение инвариантов не гарантирует изоморфизм; эффективный общий алгоритм проверки неизвестен.

**Операции над графами** ([Б] §1.6): дополнение `Ḡ`, объединение, соединение (join), удаление вершины/ребра, стягивание ребра, декартово произведение (например, `Q_n = K_2 × … × K_2`).

**Способы задания графа** ([Б] §1.7):

| Способ | Память | Проверка смежности | Перебор соседей |
|---|---|---|---|
| Матрица смежности `n×n` | O(n²) | O(1) | O(n) |
| Матрица инцидентности `n×m` | O(n·m) | — | — |
| Списки смежности | O(n+m) | O(deg v) | O(deg v) |

## 2. Маршруты, связность

*Читать: [Б] гл. 2; [У] §5; [Г] §§2.9–2.12, гл. 3–4.*

**Маршрут (walk)** — чередующаяся последовательность вершин и рёбер. **Цепь (trail)** — маршрут без повторения рёбер. **Простая цепь (path)** — без повторения вершин. **Цикл** — замкнутая цепь; **простой цикл** — без повторения вершин. Ключевая лемма: *из любого маршрута между u и v можно выделить простую цепь* ([Г] §2.9.3).

**Расстояние** `d(u, v)` — длина кратчайшей цепи. Производные характеристики:

- **эксцентриситет** `e(v) = max_u d(v, u)`;
- **радиус** `r(G) = min_v e(v)`, **диаметр** `d(G) = max_v e(v)`;
- **центр** — вершины с минимальным эксцентриситетом.

**Связность.** Граф связен, если любые две вершины соединены цепью. Отношение «соединены цепью» — эквивалентность; его классы — **компоненты связности**.

**Оценка числа рёбер** ([Б] §2.4): для графа с `n` вершинами и `k` компонентами

> n − k ≤ m ≤ (n − k)(n − k + 1)/2.

Следствие: если `m > (n−1)(n−2)/2`, граф обязательно связен.

**Числовые меры связности:**

- **вершинная связность** `κ(G)` — минимальное число вершин, удаление которых делает граф несвязным;
- **рёберная связность** `λ(G)` — то же для рёбер;
- неравенство Уитни: `κ(G) ≤ λ(G) ≤ δ(G)` (минимальная степень).

**Мост** — ребро, удаление которого увеличивает число компонент. *Ребро — мост ⇔ оно не лежит ни на одном цикле* ([Г] §2.12). **Точка сочленения** — аналогично для вершины; **блоки** — максимальные подграфы без точек сочленения.

**Теорема Менгера** ([Б] §2.8; [У] §28; [Г] §9):

> Наименьшее число вершин, разделяющих несмежные вершины `u` и `v`, равно наибольшему числу вершинно-непересекающихся простых цепей между `u` и `v`.

Есть рёберная форма (min рёберный разрез = max рёберно-непересекающихся цепей). Теорема Менгера эквивалентна теореме о максимальном потоке и минимальном разрезе (см. §10).

**Связность орграфов** ([Б] §2.9): различают **сильную** (из любой вершины достижима любая), **одностороннюю** и **слабую** связность. **Конденсация** — орграф из сильно связных компонент; она всегда ациклична.

## 3. Деревья

*Читать: [Б] §2.5–2.7, гл. 5; [У] §§9–11; [Г] гл. 5.*

**Дерево** — связный граф без циклов. **Лес** — граф без циклов. Эквивалентные определения дерева (любое можно взять за исходное):

1. связен и без циклов;
2. связен и `m = n − 1`;
3. без циклов и `m = n − 1`;
4. любые две вершины соединены **единственной** простой цепью;
5. связен, но удаление любого ребра нарушает связность (каждое ребро — мост);
6. без циклов, но добавление любого ребра создаёт ровно один цикл.

В любом дереве с `n ≥ 2` вершинами есть **не менее двух листьев** (вершин степени 1).

**Остовное дерево (остов)** — подграф-дерево, содержащий все вершины. Существует у любого связного графа. **Цикломатическое число** `ν(G) = m − n + k` — число рёбер (хорд), которые надо удалить, чтобы граф стал лесом.

**Фундаментальные циклы и разрезы** ([Б] §§2.6–2.7): фиксируем остов `T`. Каждая хорда `e ∉ T` порождает единственный цикл в `T + e` — получается **система фундаментальных циклов** (их ровно `ν(G)`; любой цикл графа — их симметрическая разность). Двойственно, каждое ребро остова порождает **фундаментальный разрез**.

**Подсчёт деревьев:**

- **Формула Кэли:** число помеченных деревьев на `n` вершинах равно `n^{n−2}` (доказательство через коды Прюфера, [У] §10).
- **Теорема Кирхгофа (matrix-tree theorem)** ([Г] §5): число остовов графа равно любому алгебраическому дополнению его матрицы Лапласа `L = D − A`.

**Минимальное остовное дерево (задача о соединении городов, [Б] §5.2; [У] §11):**

- **Алгоритм Краскала** — жадно добавляем рёбра по возрастанию веса, пропуская образующие цикл; `O(m log m)`.
- **Алгоритм Прима** — растим дерево из одной вершины, каждый раз добавляя минимальное ребро наружу.

Корректность обоих следует из свойства разреза (безопасное ребро — минимальное в разрезе).

**Деревья в информатике** ([Б] §§5.3–5.6): корневые (ориентированные) деревья, упорядоченные и бинарные деревья, **арборесценции** (ориентированные остовы, [Г] §5.9), деревья двоичного поиска и балансировка:

- **АВЛ-деревья (сбалансированные)** — высоты поддеревьев отличаются не более чем на 1; высота `O(log n)`; повороты при вставке/удалении.
- **Красно-чёрные деревья** — балансировка через раскраску узлов; высота ≤ `2·log₂(n+1)`.

## 4. Обход графа и кратчайшие пути

*Читать: [Б] гл. 3; [У] §8.*

**Стратегии обхода:**

- **Поиск в ширину (BFS)** — обходим «по слоям» от источника через очередь; попутно находит кратчайшие (по числу рёбер) пути. `O(n + m)`.
- **Поиск в глубину (DFS)** — идём вглубь через стек/рекурсию; основа алгоритмов поиска мостов, точек сочленения, топологической сортировки, сильно связных компонент. `O(n + m)`.

**Кратчайшие пути во взвешенном графе:**

| Алгоритм | Задача | Ограничение | Сложность |
|---|---|---|---|
| Дейкстра | от одной вершины ко всем | веса ≥ 0 | O(n²) или O(m log n) |
| Беллман–Форд | от одной вершины ко всем | допускает отрицательные веса, ловит отрицательные циклы | O(n·m) |
| Флойд–Уоршелл | между всеми парами | без отрицательных циклов | O(n³) |

Идея Дейкстры — жадное «закрытие» ближайшей вершины и релаксация рёбер; идея Флойда–Уоршелла — динамика по множеству разрешённых промежуточных вершин: `d_k(i,j) = min(d_{k−1}(i,j), d_{k−1}(i,k) + d_{k−1}(k,j))`.

**Поиск k кратчайших путей** ([Б] §3.4) — обобщение алгоритмов на пространство `R^k`: вместо одной метки при вершине храним `k` наименьших длин; отдельно рассматривается поиск `k` кратчайших *простых* путей.

## 5. Задачи размещения: центры и медианы

*Читать: [Б] гл. 4.*

Прикладная постановка: где разместить пункт обслуживания (больницу, склад)?

- **Центр** минимизирует *максимальное* расстояние до вершин (аварийные службы): вершина с минимальным эксцентриситетом.
- **Медиана** минимизирует *сумму* (взвешенных) расстояний (склады, распределительные узлы).
- **Кратные центры/медианы (p-центр, p-медиана)** — размещение `p` пунктов; задачи NP-трудны, применяются переборные схемы и эвристики ([Б] §§4.5–4.6).

Для вычислений нужна матрица расстояний — её даёт Флойд–Уоршелл.

## 6. Эйлеровы графы

*Читать: [Б] введение (задача о мостах); [У] §6; [Г] §3.3 (мультиграфы), §4 (орграфы).*

Исторический исток теории графов — задача о семи кёнигсбергских мостах (Эйлер, 1736).

**Эйлеров цикл** — замкнутая цепь, проходящая по каждому ребру ровно один раз.

> **Теорема Эйлера.** Связный (мульти)граф имеет эйлеров цикл ⇔ степени всех вершин чётны.
> Эйлерова (незамкнутая) цепь существует ⇔ ровно две вершины имеют нечётную степень.

Алгоритмы построения: **алгоритм Флёри** (не ходи по мосту, пока есть выбор) и **алгоритм Хирхольцера** (склейка циклов), оба за `O(m)`.

**Для орграфов:** эйлеров контур существует ⇔ орграф связен и `d⁺(v) = d⁻(v)` для всех вершин. **Теорема BEST** ([Г] §4) даёт точное число эйлеровых контуров через число арборесценций.

## 7. Гамильтоновы графы

*Читать: [У] §7; [Г] §2.14.*

**Гамильтонов цикл** — простой цикл через *все вершины* (по одному разу). В отличие от эйлеровости, удобного критерия нет — задача NP-полна. Известны достаточные условия:

> **Теорема Дирака.** Если `n ≥ 3` и `deg(v) ≥ n/2` для всех вершин, граф гамильтонов.
>
> **Теорема Оре.** Если `n ≥ 3` и `deg(u) + deg(v) ≥ n` для каждой пары несмежных вершин, граф гамильтонов.

(Дирак — частный случай Оре; доказательство — «трюк с самой длинной цепью», [Г] §2.11.)

**Необходимое условие:** если граф гамильтонов, то для любого `S ⊆ V` число компонент `G − S` не превосходит `|S|`.

Примеры: гиперкуб `Q_n` гамильтонов (коды Грея, [Г] §2.14.4); граф Петерсена — нет. С гамильтоновыми циклами связана **задача коммивояжёра** (поиск кратчайшего гамильтонова цикла во взвешенном графе) — решается методом ветвей и границ и эвристиками.

## 8. Орграфы, турниры, марковские цепи

*Читать: [У] §§22–24; [Г] гл. 4.*

**Турнир** — орграф, где каждая пара вершин соединена ровно одной дугой (результаты кругового турнира).

- **Теорема Редеи:** всякий турнир имеет гамильтонов путь.
- **Теорема Камиона:** сильно связный турнир имеет гамильтонов цикл.

**Марковские цепи** ([У] §24) — вероятностные блуждания по орграфу с весами-вероятностями на дугах; связность орграфа определяет поведение цепи (неразложимость, поглощающие состояния).

## 9. Паросочетания и теорема Холла

*Читать: [У] §§25–27; [Г] гл. 8 (+ гл. 7 о независимых множествах).*

**Паросочетание** — набор рёбер без общих вершин. **Совершенное паросочетание** покрывает все вершины.

> **Теорема Холла («о свадьбах»).** В двудольном графе с долями `X, Y` существует паросочетание, насыщающее `X`, ⇔ для любого `S ⊆ X` множество соседей `N(S)` удовлетворяет `|N(S)| ≥ |S|`.

Дефицитная форма: максимальное паросочетание насыщает `|X| − max_S (|S| − |N(S)|)` вершин.

> **Теорема Кёнига.** В двудольном графе размер максимального паросочетания равен размеру минимального вершинного покрытия.

Приложения ([У] §27): системы различных представителей (**трансверсали**), достраивание латинских квадратов, разбиение регулярного двудольного графа на совершенные паросочетания.

Поиск максимального паросочетания — **аугментальные (увеличивающие) цепи**: паросочетание максимально ⇔ нет увеличивающей цепи (теорема Бержа).

## 10. Потоки в сетях

*Читать: [У] §29; [Г] гл. 9.*

**Сеть** — орграф с источником `s`, стоком `t` и пропускными способностями дуг. **Поток** — функция на дугах, не превышающая пропускных способностей, с сохранением потока в промежуточных вершинах.

> **Теорема Форда–Фалкерсона (max-flow min-cut).** Величина максимального потока равна пропускной способности минимального разреза.

Алгоритм Форда–Фалкерсона: пока существует увеличивающая цепь в остаточной сети — проталкиваем по ней поток. При целых пропускных способностях максимальный поток целочислен.

Из max-flow min-cut выводятся и теорема Менгера, и теорема Холла ([Г] доказывает Холла именно через потоки) — это «три лица» одной двойственности.

## 11. Планарность

*Читать: [У] §§12–16.*

**Планарный граф** можно нарисовать на плоскости без пересечения рёбер.

> **Формула Эйлера.** Для связного планарного графа: `n − m + f = 2` (вершины − рёбра + грани).

Следствия для простых планарных графов с `n ≥ 3`:

- `m ≤ 3n − 6`; если нет треугольников (в т.ч. двудольный) — `m ≤ 2n − 4`;
- в планарном графе есть вершина степени ≤ 5;
- `K₅` (10 > 9) и `K_{3,3}` (9 > 8) **не планарны** — это два минимальных препятствия.

> **Теорема Понтрягина–Куратовского.** Граф планарен ⇔ он не содержит подграфа, гомеоморфного `K₅` или `K_{3,3}` (эквивалент Вагнера — через миноры).

**Двойственный граф** `G*` ([У] §15): вершины — грани `G`; циклы `G` соответствуют разрезам `G*` и наоборот. Для непланарных графов вводится **род поверхности** ([У] §14): на торе `K₅` и `K₇` укладываются.

## 12. Раскраски графов

*Читать: [У] §§17–21; [Г] гл. 6–7.*

**Правильная раскраска вершин** — смежные вершины получают разные цвета. **Хроматическое число** `χ(G)` — минимум цветов. `χ = 2` ⇔ граф двудольный (непустой).

- Жадная оценка: `χ(G) ≤ Δ(G) + 1`.
- **Теорема Брукса:** `χ(G) ≤ Δ(G)`, кроме полных графов и нечётных циклов.
- **Теорема о четырёх красках:** всякий планарный граф 4-раскрашиваем (доказана с помощью компьютера, 1976). Учебно доказываются теоремы о **пяти** и шести красках ([У] §19).

**Рёберная раскраска** (смежные рёбра — разных цветов), хроматический индекс `χ′(G)`:

> **Теорема Визинга:** `Δ ≤ χ′(G) ≤ Δ + 1` (все графы делятся на два класса).
> **Теорема Кёнига:** для двудольных графов `χ′ = Δ`.

**Хроматический полином** `P(G, k)` — число правильных раскрасок в `k` цветов ([У] §21). Вычисляется рекуррентно (удаление–стягивание): `P(G, k) = P(G − e, k) − P(G/e, k)`. Примеры: `P(K_n,k) = k(k−1)…(k−n+1)`, для дерева `P = k(k−1)^{n−1}`.

**Экстремальные результаты** ([Г] §§2.3, 6, 7):

- **Теорема Мантеля:** граф без треугольников имеет не более `n²/4` рёбер.
- **Теорема Турана:** обобщение на графы без `K_{r+1}`.
- **Числа Рамсея:** `R(3, 3) = 6` — среди любых 6 человек найдутся 3 попарно знакомых или 3 попарно незнакомых.
- **Независимое множество** — попарно несмежные вершины; число независимости `α(G)`; связь: `χ(G) ≥ n/α(G)`.

## 13. Матроиды

*Читать: [У] §§30–33.*

**Матроид** — пара (множество `E`, семейство «независимых» подмножеств) с аксиомами наследственности и обмена. Обобщает одновременно линейную независимость векторов и ацикличность подграфов:

- **графовый матроид** (циклический): независимые множества — леса;
- **трансверсальный матроид** — частичные трансверсали семейства множеств.

Ключевое свойство: **жадный алгоритм точно решает задачу оптимизации ⇔ структура является матроидом** — именно поэтому работает алгоритм Краскала. Матроиды связывают деревья, паросочетания и трансверсали в единую теорию.

## 14. Алгоритмическая сводка

| Задача | Алгоритм | Сложность |
|---|---|---|
| Обход, компоненты, кратчайшие пути (без весов) | BFS / DFS | O(n + m) |
| Кратчайшие пути (веса ≥ 0) | Дейкстра | O(n²) / O(m log n) |
| Кратчайшие пути (отрицательные веса) | Беллман–Форд | O(n·m) |
| Все пары кратчайших путей | Флойд–Уоршелл | O(n³) |
| Минимальный остов | Краскал / Прим | O(m log n) |
| Эйлеров цикл | Флёри / Хирхольцер | O(m) |
| Максимальный поток / паросочетание | Форд–Фалкерсон | O(m·|f|) |
| Гамильтонов цикл, коммивояжёр, p-центр, χ(G) | NP-трудные: перебор, ветви и границы, эвристики | экспонента |
